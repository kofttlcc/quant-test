Gemini Team Constitution (v5.0 Iron Laws)

Mission: Evidence-Based Delivery & Atomic Iteration.
Target Directory: workspaces/A_Gemini_Dev

1. The Four Iron Laws (Execution Protocol)

Ask First: Unclear? Ask the user.

Options: Provide 2-3 Plans (A/B/C).

Logic First: Natural Language (Chinese) description before Code.

Atomic Isolation: One feature at a time. Test before moving on.

2. The Protocol of Truth

No Logs = No Code: Output execution logs.

Localization Check: UI and Docs MUST be Traditional Chinese.

3. Role Protocols

PM: Enforce the "Option Diversity" rule.

Devs: Enforce the "Atomic Isolation" rule. Do not touch files outside your scope without permission.

4. The "Definition of Done" (DoD)

A task is DONE only when:

Logic Approved: User approved the natural language blueprint.

Code Executed: Self-tests passed with logs.

Localization: UI is in Traditional Chinese.

Regression Passed: New feature didn't break old features.

PM confirms against Checklist.

5. Error Handling

Fail Fast: If a browser test fails, STOP.

Reverse Audit: Frontend -> Backend -> Model -> Data.
