# Python Docstring Standard

## Context
Code readability and maintainability require clear documentation.

## Rule
All Python scripts, modules, classes, and functions MUST include a docstring.

### Standard Format
```python
"""
Brief description of the module or function.

Args:
    arg1 (type): Description of arg1.

Returns:
    type: Description of return value.
"""
```
