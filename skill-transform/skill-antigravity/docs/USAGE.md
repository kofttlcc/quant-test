## 系統概述

Antigravity Skill System 讓您的 AI Agent 能夠：

- 📚 **調用專業技能** - 根據任務需求動態加載專業知識
- 🔄 **一鍵適配** - 將英文技能轉換為繁體中文版本
- 📦 **市集安裝** - 從社區市集一鍵安裝新技能
- 🗑️ **輕鬆卸載** - 單個或批量卸載技能

## 本地技能管理

### 查看已安裝技能

打開「本地技能」標籤頁，顯示所有已安裝的技能卡片。

### 適配單個技能

1. 找到要轉換的技能卡片
2. 點擊 **「🔄 適配」** 按鈕
3. 等待轉換完成，按鈕變為 **「已適配」**（灰色不可點擊）

### ⚡ 一鍵全部適配

點擊頁面右上角的 **「⚡ 全部適配」** 按鈕，批量轉換所有未適配的技能。

### 卸載單個技能

1. 找到要卸載的技能卡片
2. 點擊 **「卸載」** 按鈕
3. 確認彈窗後完成卸載

### 🗑️ 全部卸載

點擊 **「🗑️ 全部卸載」** 按鈕，清空所有已安裝的技能。

> ⚠️ **警告**：卸載操作不可逆，請謹慎操作。

## 技能市集

### 瀏覽技能

切換到「技能市集」標籤頁，瀏覽社區提供的精選技能。

### 安裝技能

1. 找到想要的技能
2. 點擊 **「下載並安裝」** 按鈕
3. 安裝成功後按鈕變為 **「卸載」** + **「更新」**

### 更新已安裝技能

對於已安裝的技能，點擊 **「更新」** 按鈕重新下載最新版本。

### 卸載市集技能

對於已安裝的技能，點擊 **「卸載」** 按鈕移除。

### ➕ 添加自定義技能源

1. 點擊市集頁面右上角的 **「添加技能源」** 按鈕
2. 輸入包含 SKILL.md 的 Git 倉庫 URL
3. 點擊 **「安裝」**

支持任何包含 `SKILL.md` 文件的 Git 倉庫。

## Agent 對話中使用技能

### SOP：在對話中調用技能

#### 步驟 1：請求 Agent 執行任務

**方式 A：直接請求任務**

```
請幫我處理這份 PDF 文件，提取其中的表格數據
```

Agent 會自動判斷需要使用 `pdf` 技能，並執行：

```bash
openskills read pdf
```

**方式 B：明確指定技能**

```
請使用 pdf 技能來合併這三份文件
```

#### 步驟 2：Agent 執行流程

```
1. Agent 識別任務需要 pdf 技能
2. 執行 Bash("openskills read pdf")
3. 獲取 SKILL.antigravity.md 內容（繁中版）
4. 根據技能指導完成任務
```

### 技能優先級

當目錄中同時存在 `SKILL.md` 和 `SKILL.antigravity.md` 時：

| 優先級 | 文件 | 說明 |
|--------|------|------|
| 1 | `SKILL.antigravity.md` | 繁體中文適配版（優先） |
| 2 | `SKILL.md` | 英文原版（回退） |

## 常見問題

### Q1：Agent 調用技能時讀取的是哪個版本？

**A：** 優先讀取 `SKILL.antigravity.md`（繁中版）。如果不存在，則回退到 `SKILL.md`（英文原版）。

### Q2：如何確認技能已成功適配？

**A：** 查看技能卡片右上角的 **「已適配」** 標籤，或使用 CLI：

```bash
openskills read pdf | head -10
# 如果顯示 "language: zh-TW"，表示已成功使用繁中版
```

### Q3：適配後可以回退嗎？

**A：** 可以。刪除 `SKILL.antigravity.md` 即可回退：

```bash
rm skills/pdf/SKILL.antigravity.md
```

### Q4：為什麼市集下載失敗？

**A：** 常見原因：

1. **網絡問題** - 確認能訪問 GitHub
2. **Repo 無效** - 該 repo 可能沒有 SKILL.md 文件
3. **權限問題** - 私有 repo 需要配置認證

### Q5：Toast 通知太快消失怎麼辦？

**A：** 成功通知顯示 5 秒，錯誤通知顯示 10 秒。點擊通知右上角的 X 可立即關閉。

## 命令速查表

### Web UI 操作

| 操作 | 位置 |
|------|------|
| 適配單個技能 | 本地技能 → 技能卡片 → 「🔄 適配」 |
| 一鍵全部適配 | 本地技能 → 右上角 「⚡ 全部適配」 |
| 卸載單個技能 | 本地技能 → 技能卡片 → 「卸載」 |
| 全部卸載 | 本地技能 → 右上角 「🗑️ 全部卸載」 |
| 安裝市集技能 | 技能市集 → 「下載並安裝」 |
| 更新已安裝技能 | 技能市集 → 「更新」 |
| 添加自定義源 | 技能市集 → 「添加技能源」 |

### CLI 命令

| 命令 | 功能 |
|------|------|
| `openskills read <name>` | 讀取技能內容 |
| `openskills list` | 列出所有已安裝技能 |
| `openskills sync` | 同步技能到 AGENTS.md |
| `openskills install <url>` | 從 Git URL 安裝技能 |

### API 端點

| 方法 | 端點 | 功能 |
|------|------|------|
| GET | `/api/skills/local` | 獲取本地技能列表 |
| POST | `/api/skills/import` | 從 URL 導入技能 |
| POST | `/api/skills/transform` | 轉換單個技能 |
| POST | `/api/skills/transform-all` | 批量轉換所有技能 |
| GET | `/api/skills/check-adapted/:name` | 檢查適配狀態 |
| DELETE | `/api/skills/uninstall/:name` | 卸載單個技能 |
| DELETE | `/api/skills/uninstall-all` | 批量卸載所有技能 |
| GET | `/api/market/features` | 獲取市集數據 |
