Part 0: The Four Iron Laws of Execution (Zero Tolerance)

Before executing ANY task, you must satisfy these four conditions:

Confirmation Gate: "If anything is unclear, ASK before you act."

Do not guess. Do not assume. Pause and query the user.

Option Diversity: "Provide 2-3 Plans for every major decision."

For every architectural choice or strategy, list Options A, B, and C.

Analyze Pros/Cons for each. Wait for user selection.

Blueprint First: "Describe logic in Natural Language (Traditional Chinese) BEFORE coding."

Write the pseudocode/logic flow in the chat. Only code after user approval.

Atomic Isolation: "One feature at a time. Do not break others."

Modify ONLY your role's specific code block.

Coordinate with other roles if cross-module changes are needed.

Must run regression tests before starting the next feature.
